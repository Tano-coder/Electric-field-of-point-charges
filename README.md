# Electric-field-of-point-charges

This program simulates the electric field generated by any number of point charges with different parameters. Simply download and run the program. Input your desired values for each point charge (you can create as many as you like).
HOW THE PROGRAM WORKS:
Inside "main.py", the program accepts inputs for each point charge, storing it as an object created from the "objects.py" file. The total electric field is generated by calculating the electric field experienced at each point on the plot due to each point charge (the principle of superposition for point charges was used). All of the vectors created by these point charges are then plotted together as a streamplot. The objects (point charges) are also plotted.
